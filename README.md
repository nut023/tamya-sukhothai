# TAMYA - ระบบติดตามประวัติยาระหว่างโรงพยาบาลในจังหวัดสุโขทัย (Sukhothai MedTrack)

ระบบเว็บแอปพลิเคชัน Real-time สำหรับงานเภสัชกรรมและทีมบุคลากรทางการแพทย์ เพื่อติดตามประวัติการใช้ยาของผู้ป่วยข้ามโรงพยาบาลในสังกัด สสจ.สุโขทัย ทั้ง 9 อำเภอ

---

## คุณสมบัติเด่นของระบบ

1. **Dashboard แผนที่สุโขทัย Interactive (Leaflet OpenStreetMap)**:
   - ปักหมุดโรงพยาบาลทั้ง 9 แห่งตามพิกัดจริงใน จ.สุโขทัย พร้อมตราสัญลักษณ์ (Logo) เฉพาะของแต่ละ รพ.
   - แสดงสถานะจำนวนคำขอที่ค้างอยู่ (Pulse Warning Ring) บนหมุดแผนที่
   - คลิกที่ Logo รพ. ใดเพื่อเปิดแบบฟอร์มส่งคำขอตามประวัติยาได้ทันที

2. **หน้ากำหนด รพ.ต้นทาง และช่องทางการติดต่อกลับ**:
   - เลือก รพ. ที่ตนเองปฏิบัติการอยู่
   - กำหนดชื่อผู้ติดต่อ (เภสัชกร/พยาบาล), เบอร์โทรภายใน/ห้องยา, เบอร์ตรง/มือถือ, และ LINE ID
   - ระบบจดจำค่าอัตโนมัติ ไม่ต้องพิมพ์ซ้ำ

3. **ระบบแจ้งเตือน Real-time และปุ่ม "🟢 กดรับการตามยา" ฝั่ง รพ.ปลายทาง**:
   - เมื่อ รพ.ต้นทาง กดส่งคำขอ หน้าจอ รพ.ปลายทางจะส่งเสียงสัญญาณเตือนฉุกเฉิน (Chime Alert) และเปิด Pop-up อัตโนมัติ
   - แสดงข้อมูลผู้ป่วย (ชื่อ, HN, CID, รายการยาที่ขอ) และช่องทางการติดต่อกลับอย่างเด่นชัด
   - **ปุ่ม "🟢 กดรับการตามยา" (Acknowledge)**: เมื่อคลิกแล้วจะส่งสัญญาณแจ้งเตือนกลับไปยัง รพ.ต้นทางทันทีว่า "รับเรื่องแล้ว กำลังค้นหาข้อมูล"
   - **ปุ่ม "✅ ส่งประวัติยาเรียบร้อยแล้ว (ปิดเคส)"**: สำหรับปิดงานเมื่อประสานงานเสร็จสิ้น

4. **กระดานติดตามประวัติคำขอ (Live Tracker)**:
   - แบ่งหมวดหมู่: "คำขอที่ส่งถึงเรา (Incoming)", "คำขอที่เราส่งไป (Outgoing)", "ทั้งเครือข่ายสุโขทัย (All Network)"
   - กรองตามสถานะ: รอดำเนินการ / รับเรื่องแล้ว / ส่งประวัติยาแล้ว
   - ค้นหาด่วนด้วยชื่อคนไข้หรือ HN

## วิธีการเริ่มต้นใช้งาน (Getting Started)

### วิธีที่ 1: รัน Development Mode (แนะนำสำหรับแก้ไขโค้ด)
เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
npm run dev
```
- ระบบจะรัน Backend Realtime Server (Port 4000) และ Vite Frontend (Port 5173) พร้อมกัน
- เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`

### วิธีที่ 2: รัน Production / Single Server Mode
```bash
npm run server
```
- เปิดเบราว์เซอร์ไปที่: `http://localhost:4000`

## การทดสอบการส่งคำขอและรับแจ้งเตือนแบบ Real-time
1. **เปิด Browser 2 แท็บพร้อมกัน**:
   - **แท็บ 1**: ที่มุมขวาบน ให้เลือกเป็น **"รพ.สุโขทัย"**
   - **แท็บ 2**: ที่มุมขวาบน ให้เลือกเป็น **"รพ.สวรรคโลก"**
2. **จาก แท็บ 1 (รพ.สุโขทัย)**:
   - คลิกที่ Logo **"รพ.สวรรคโลก"** บนแผนที่
   - กรอกชื่อผู้ป่วย และระบุยาที่ต้องการ (เช่น ขอยาเบาหวาน/ความดัน)
   - กดปุ่ม **"ส่งคำขอตามประวัติยาเดี๋ยวนี้"**
3. **ดูผลที่ แท็บ 2 (รพ.สวรรคโลก)**:
   - แท็บ 2 จะมีเสียงสัญญาณเตือนกระดิ่ง และ Pop-up เด้งขึ้นมาทันที!
   - แสดงเบอร์โทรและ LINE ID ของ รพ.สุโขทัย
   - **คลิกปุ่ม "🟢 กดรับการตามยา"**
4. **ดูผลย้อนกลับที่ แท็บ 1**:
   - หน้าจอ รพ.สุโขทัย จะได้รับการแจ้งเตือน Toast สีเขียวทันทีว่า *"รพ.สวรรคโลก ได้กดรับการตามยาของท่านแล้ว"*
